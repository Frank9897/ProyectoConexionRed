# Perfiles visuales por modelo

Este directorio contiene ilustraciones SVG locales asociadas a modelos exactos. El perfil debe identificarse por fabricante y modelo completo en `Services/CatalogoVisualesDispositivos.cs` y contar con una fuente técnica para su capacidad.

Las variantes incompletas o no catalogadas usan el icono genérico y la capacidad ingresada en el inventario. No se incorporan fotografías de terceros ni se consulta contenido remoto al abrir Topología.

Las figuras de switch son esquemáticas. La cuadrícula de puertos se genera desde los datos validados y no depende de los puertos dibujados dentro del archivo SVG.
